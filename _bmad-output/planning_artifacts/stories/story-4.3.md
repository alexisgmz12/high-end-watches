# Story 4.3: Build ProductCard component

**Story ID:** 4.3
**Title:** Build `ProductCard` component
**User Story / Description:** As a developer, I need a card that displays product image, name and price; it shows a hover zoom, uses proper ARIA roles and is responsive.
**Acceptance Criteria:**
- Displays image, name, price.
- Hover zoom effect.
- Proper ARIA roles.
- Responsive.
**Dependencies:** 2.3
**Technical Considerations:**
- Create `src/components/ProductCard.tsx`.
- Use an accessible image `alt={product.name}`.
- Use CSS modules or styled‑components for responsive layout.
